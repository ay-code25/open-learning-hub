
# Open Learning Hub | Interactive Mathematics

An open-source mathematics learning platform featuring
interactive graphs, visual explanations, mathematical
proofs, worked examples and step-by-step exercises.

## Current Learning Topics
- Conic Sections
- Polar Coordinates
- Circles, Ellipses, Parabolas and Hyperbolas
- Mathematical Equations and Theorems
- Interactive Geometry

## Planned Technology
- Next.js
- React
- TypeScript
- Tailwind CSS
- Interactive Mathematical Visualisations

## Development Goals
- Accessible learning for ages 10–14
- Bright, clear and interactive graphics
- Graphs that respond to changing parameters
- Detailed mathematical proofs and solutions
- Mobile-friendly and accessible design
- Open-source collaboration
