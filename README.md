# مقاطع مخروطی و مختصات قطبی | آموزش تصویری

A free, interactive mathematics learning website in Dari, with a colourful interface for ages 10–14. Includes 11 chapters, 22 interactive example visuals, worked exercises and proofs. Some advanced chapters are enrichment material and may require teacher support.

## Usage
Open `index.html` in a current browser. No server required for local reading. Publish the folder to static hosting to share an HTTPS link.

## Contributing
See CONTRIBUTING.md. Mathematical material should be independently checked before classroom adoption.
